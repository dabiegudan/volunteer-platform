# 用户操作文档

> 项目版本：2.3.0

一页说明**主流程**。角色能做什么、接口怎么调用等细节见《角色功能详细文档》与《后端接口API文档》。

---

## 一、登录与首次准备

1. 打开平台地址（容器形态为 `http://localhost/` 或 `http://localhost:8080`，取决于部署方式）。
2. 在登录页输入**手机号、学号或用户名** + 口令。连续输错口令达到 3 次会被临时锁定 5 分钟（阈值可在配置中调整）；若管理员开启了滑块验证，登录前还需先通过滑块。
3. 没有账号就点"注册"，按提示填写；口令需 8–32 位且同时包含大写字母、小写字母、数字、特殊字符。
4. 内置测试账号（首次登录后请改口令）：

   | 用户名 | 口令 | 角色 |
   |---|---|---|
   | `admin` | `Admin@2026Safe` | 超级管理员 |
   | `organizer` | `Organizer@2026` | 活动组织者 |
   | `volunteer1` | `Volunteer@2026` | 志愿者 |
   | `college_admin1` | `College@Admin2026` | 学院管理员 |
   | `auditor` | `Auditor@2026` | 系统审核员 |

5. **绑定学号**（志愿者必须做，否则不能报名和签到）：进入"绑定学号"页面，填写真实学号并再次输入登录口令确认。绑定成功后账号从"访客"升级为完整用户。
6. **完善资料**：资料不完整时，点击"报名"或"签到"会被拦下并提示"请先完善个人档案资料后再进行操作"，系统会直接弹出资料填写抽屉，填完即可继续。

## 二、志愿者主流程

```
登录 → 绑定学号 → 浏览活动 → 报名 → （组织者审核）→ 现场扫码签到 → 查看时长与报表
```

1. **浏览活动**：在活动列表查看可报名的活动（未绑学号也能看到全校公开活动）；点进"活动详情"查看时间、地点、人数上限、剩余名额与要求。
2. **报名**：在活动详情页点"报名"。提交后状态为"待审核"；组织者审核通过后报名生效，可在"我的活动"里查看。
3. **现场签到**：活动开始时，用手机扫描组织者出示的签到二维码完成签到。签到需要在活动地点附近（默认 500 米以内），超出距离会被拒绝。
4. **漏签补签**：进入"志愿工具 → 补签申请"提交补签，等待组织者审核。
5. **查看成果**：在"我的 → 个人报表"查看累计服务时长与参与记录；在"数据统计"查看图表；信用分与徽章同样在个人中心查看。

## 三、常用入口

登录后进入工作台，可通过"客户端页面"使用志愿者端功能：

| 入口 | 能做什么 |
|---|---|
| 我的活动 | 查看已报名/已参加的活动及其状态 |
| 消息中心 | 站内信与系统公告，实时推送新消息 |
| 待办清单 | 需要你处理的事项（待审核、待签到、待评价等） |
| 志愿工具 | 补签申请等常用工具 |
| 个人中心 | 个人资料、绑定学号、时长与信用、退出登录 |
| 服务咨询 | AI 助手，可询问活动推荐、平台使用、志愿常识 |

## 四、组织者与管理员

- **组织者**：在"活动管理"创建活动（草稿 → 提交审核 → 审核通过后发布），管理报名审核、二维码签到、补签审核、活动导入；只能操作本院活动。
- **学院管理员**：审核本院活动。
- **系统审核员**：审核活动（通过 / 拒绝 / 审核意见）。
- **超级管理员**：在"用户学院"管理用户与角色、绑定学院；在"考勤失信"处置违规记录；在"统计报表"看全校数据；在"公告发布"发公告；在"审计日志"查后台操作；另有系统配置、信用与时间银行调账等能力。

## 五、常见问题

| 现象 | 处理 |
|---|---|
| 报名/签到时提示"请先绑定学号" | 先完成学号绑定；绑定入口在个人中心 |
| 提示"请先完善个人档案资料" | 按弹出的抽屉补齐资料后再操作 |
| 提示"token已过期" | 重新登录（令牌默认有效期 24 小时） |
| 提示"权限不足" | 当前账号角色不满足该操作要求；组织者只能操作本院活动 |
| 扫码签到提示距离过远 | 走到活动地点附近再签到，或请组织者协助补签 |
| 页面空白 / 所有请求失败 | 属部署问题：前端产物未构建，或构建时未设置正确的接口地址，见《项目启动与配置指南》§7 |
| 收不到短信验证码 | 开发环境验证码只打印在后端日志里 |
| AI 咨询报错 | 未配置或配置错误的大模型密钥，请联系管理员 |
